# Hospital Patient Record Management System

## About the Project

The Hospital Patient Record Management System is a C programming
project developed as part of my Bachelor of Information Technology
studies.

The project is designed to manage hospital patient records in a
structured manner and provides an opportunity to apply programming
and problem-solving concepts using the C programming language.

## Technology Used

- C Programming

## Project Purpose

The purpose of this project is to practice programming concepts and
develop a simple system for managing patient-related records.
